# 大肥鱼桌宠 · DSwhale Desktop Pet

一只住在桌面上的 Live2D 桌宠：**大肥鱼**（**四套形象**随时切换 —— Q肥鱼 / 中肥鱼 / 成年肥鱼 / 小肥鱼）。

她会跟你聊天、记住你说过的事、慢慢形成对你的印象；你玩游戏看视频时她随口评论两句，
会陪你读书、给你放歌；也会累、会睡着，你回来找她又会醒。
平时她会自己找点事做——挤番茄酱、吹泡泡、自拍——身上的装扮也能随你换。

> 本仓库**只包含大肥鱼这一只**，且**包含她的四套 Live2D 形象素材**（均为 CC 协议传播的非盈利二次创作，署名见下「许可」）。

---

## 她会做什么

| 功能 | 说明 |
|---|---|
| 💬 对话 | 接入任意 OpenAI 兼容接口（DeepSeek / Ollama / 其他），有独立人设（可在设置里改）：青春可爱的 DeepSeek 拟人化鲸鱼娘、聪明但偶尔犯傻、最爱偷吃大白饭 |
| 🧠 记忆 | 聊天里提到的偏好与经历会存成记忆，形成「性格画像」与「关系形象」，下次主动提起 |
| 🎤 语音输入 | 本地 sherpa-onnx 识别，喊名字（前 2~3 字）唤醒，8 秒内免唤醒 |
| 🔊 语音输出 | Edge TTS 或火山引擎声音复刻（默认关闭，需自配 Key / 音色） |
| 🎮 陪玩 | 隔一段时间看一眼你的屏幕、随口评论（需另配「视觉模型」；画面没变就不吭声、不浪费调用） |
| 📖 读书 | 框选屏幕区域，OCR 读出你在读什么，陪你读并评论 |
| 🎵 音乐 | 本地曲库播放，支持语音点歌与「说完再播」 |
| 🎭 形象 | 四套形象一键切换：**Q肥鱼**（最初的鲸鱼娘，8 段模型动作 + 8 个装扮槽）、**中肥鱼**、**成年肥鱼**（这两套用表情反应）、**小肥鱼**（自带 吃饭 / 吃token 动作，装扮槽「头顶 → 钢盆」）；每套各自的构图、情绪表情池与署名 |

## 快速上手（从源码运行）

1. **Windows x64 + Python 3.10**（live2d-py 的 Cubism native 是 cp310 扩展，3.11/3.12 装不上）
2. 装依赖：
   ```bat
   python -m pip install -r requirements.txt
   ```
3. 下模型（语音识别用，约 244MB，带 SHA256 校验；不下只是"语音识别"用不了）：
   ```bat
   python tools/fetch_models.py
   ```
   想要记忆向量召回更准，再加 `--with-bge`（多 92MB）。
4. 双击 **`run.bat`**（或 `python Dafeiyu.py`）。首次启动要解压/加载模型，等十几秒。
5. **右键点她 → ⚙️ 设置 → API 密钥 → 文本模型设置…**，选提供方预设、填你自己的 Key，保存。
   不填这一步她不会回话。

## 操作

| 操作 | 效果 |
|---|---|
| 左键点她 | 触摸反应（随机播一段触摸动作）；陪玩模式下等于手动让她看一眼屏幕 |
| 按住拖动 | 把她挪到桌面任意位置 |
| 右键点她 | 主菜单：语音开关 / 切换 TTS / 陪玩 / 读书 / 音乐 / 🎩 装扮 / 设置 |
| 输入框回车 | 打字聊天（输入框可以隐藏，右上角菜单里可再打开） |
| 喊名字 | 开启语音后喊「大肥鱼」（前 2~3 字即可），8 秒内可直接说话 |
| 🎩 装扮 | 眼镜 / 贴纸 / 发饰 / 桌布 / 魔爪 / 桌面摆设 / 桌面显示（可多选）/ 手持道具 |

## 数据放在哪

运行时数据都在 `userdata/`（**不会**上传到任何地方）：

| 文件 | 内容 |
|---|---|
| `config.json` | 所有设置：模型与密钥、TTS、话题定时器、陪玩/读书、缩放、输入框状态 |
| `memory.db` / `memories.json` | 记忆库（话题、事件、性格画像、关系形象） |
| `chats.json` | 聊天记录 |
| `dafeiyu.log` | 运行日志——出问题先看它 |
